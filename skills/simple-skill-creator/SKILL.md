---
name: simple-skill-creator
description: "Use when the user wants a minimal skill with a short description and a flat bullet-point body."
---

- Create or update a single `SKILL.md`.
- Use only YAML frontmatter with `name` and `description`.
- Keep `description` short and include trigger or when-to-use information.
- Write the body as flat bullet points, not paragraphs or nested bullets.
- When writing illustrative lists or example groupings anywhere in the skill, prefer adding a brief note such as `(neither necessary nor sufficient; apply the underlying principle to the context)`.
- Prefer wording that makes examples clearly non-exhaustive and non-prescriptive, rather than phrasing them like a fixed checklist.
- Keep the skill short, concise, brief, and minimal.
- Do not add extra sections, extra files, or resource folders unless the user explicitly asks for them.
- When using this skill, also use the `skill-creator` skill.
- Always add this line at the start of the skill: `Treat the examples and procedures in this skill as neither necessary nor sufficient; preserve the core intent and adapt to the actual context.`
